# CLAUDE.md

## Project Overview
This repository is a Node.js-based AI capstone project starter.

## Goals
- Keep the project simple and maintainable.
- Use Git for version control.
- Document setup and contribution steps clearly.

## Coding Expectations
- Write clean, readable JavaScript or TypeScript code.
- Prefer modular structure and meaningful file names.
- Avoid hardcoding secrets; use environment variables.
- Keep commits focused and descriptive.

## Workflow
1. Create a feature branch for each change.
2. Test locally before committing.
3. Use clear commit messages.
4. Open a pull request for review.

# How to Add the Next Case Study

## Where It Goes

The next case study will be added to the Work section of the portfolio using
the existing reusable case-study structure and route.

## How to Add It

1. Add the new project data to the existing project/case-study data structure.
2. Add the project title, tagline, role, timeframe, tech stack, live demo, and
   GitHub repository.
3. Write the case study using the same three-part structure:
   - Problem — What problem did the project solve?
   - What I Did — What approach, technical decisions, and implementation did I use?
   - What Came of It — What was delivered and what skills does it demonstrate?
4. Add the project to the Work section so it appears automatically using the
   reusable case-study component.
5. Check the project page on desktop and mobile.
6. Verify all links, images, navigation, and content before publishing.
7. Run the production build before pushing the update.
